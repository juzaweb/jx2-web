# Example Images — real JX2 (Võ Lâm Truyền Kỳ 2) UI reference

Human-curated screenshots from the retail game, provided as a **trusted visual
reference** for the jx2-web demo — layout, information density, HUD panels, and
atmosphere.

**Inspiration only:**

- Do NOT copy the artwork/assets into the repo or the shipping game.
- Match *structure, panel grouping, and feel* — never reproduce copyrighted art.

## Index

- `game-overview-hud.png` — Full game view (stone plaza, city map): isometric world
  with player, NPCs and a flying mount; top-left vitals (HP/MP bars) and target
  name; top-right map/minimap area with `Nhiệm Vụ` (quest log); right `Hành trang`
  inventory grid with item stacks (`x500`) and currency (Bạc / Tiên Xu / Kim
  Phiếu); bottom hotbar slots 1-8 with skill icons; chat box with channel tabs
  (Tổng hợp / Mật / Hệ thống / Môn phái) and a `Cận` channel label.
- `character-panel.png` — `Nhân vật` (Character) panel: tabs Trang bị / Tin tức /
  Thú nuôi; paper-doll equipment slots (left), character model (center), detailed
  stat list (right: Sinh / Nội / Thể, Ngoại công, Nội kích, Ngoại phòng, Nội
  phòng, …), attribute row (Sức mạnh, Nội công, Căn cốt, Thân pháp, Linh hoạt)
  with `+` buttons, and points (`Điểm`, `Tàng cấp`).
- `inventory-panel.png` — `Hành trang` (Inventory) window: item grid with `x500`
  stacks and per-rarity glows, weight bar (`Sức nặng 252/2085`), currency footer.
- `martial-skills-panel.png` — `Võ công` (Martial skills) window: tabs (Võ công /
  Sống / Mật tịch / Bí kíp) and a connected skill tree (Thiếu Lâm La Hán Công)
  with a tooltip listing the level cap and training requirements.
